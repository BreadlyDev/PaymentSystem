# Backend Payment system for Programming championship Hackaton



## Технический стек

Python, Django, SQLite


## Как собрать и запустить проект


### Зависимости
- `python`>=3.12.0



### Перед запуском проекта

Создание виртуального окружения
```
python -m venv myenv
```

Скачивание зависимостей
```
pip install -r requirements.txt
```

### Запуск проекта

Следует провести миграции
```
python manage.py makemigrations
python manage.py migrate
```


Для запуска проекта

```
python manage.py runserver
```

```note
Если у вас линукс, вместо python используйте python3
```


## Документация API платежной системы

### Базовый URL

`http://127.0.0.1:8000/api/v1`

Этот документ предоставляет обзор доступных конечных точек API системы платежей, включая необходимые параметры и ожидаемые ответы для каждой конечной точки.

## Конечные точки

### 1. **Приложения**

#### a. **Получить все приложения**

- **Конечная точка:** `GET /app/all`
- **Описание:** Получает список всех приложений.
- **Параметры:** Нет
- **Ответы:**
  - **200 OK:** Возвращает список приложений с их учетными данными и подробностями.

#### b. **Получить аналитику всех приложений**

- **Конечная точка:** `GET /app/all/analytics`
- **Описание:** Получает аналитику для всех приложений.
- **Параметры:** Нет
- **Ответы:**
  - **200 OK:** Возвращает список аналитических данных приложений, таких как доходы и транзакции.

#### c. **Создать приложение**

- **Конечная точка:** `POST /app/create`
- **Описание:** Создает новое приложение.
- **Параметры:**
  - **Тело запроса:** 
    ```json
    {
      "owner": {
        "email": "string",
        "password": "string"
      },
      "title": "string",
      "account": "string"
    }
    ```
- **Ответы:**
  - **201 Created:** Возвращает данные созданного приложения.

#### d. **Получить приложение по ID**

- **Конечная точка:** `GET /app/{id}`
- **Описание:** Получает подробности конкретного приложения по ID.
- **Параметры:**
  - **Параметр пути:** `id` (integer)
- **Ответы:**
  - **200 OK:** Возвращает подробности приложения.

#### e. **Обновить приложение по ID**

- **Конечная точка:** `PUT /app/{id}`
- **Описание:** Обновляет подробности конкретного приложения по ID.
- **Параметры:**
  - **Параметр пути:** `id` (integer)
  - **Тело запроса:**
    ```json
    {
      "owner": {
        "email": "string",
        "password": "string"
      },
      "title": "string",
      "account": "string"
    }
    ```
- **Ответы:**
  - **200 OK:** Возвращает обновленные данные приложения.

#### f. **Частично обновить приложение по ID**

- **Конечная точка:** `PATCH /app/{id}`
- **Описание:** Частично обновляет подробности конкретного приложения по ID.
- **Параметры:**
  - **Параметр пути:** `id` (integer)
  - **Тело запроса:** Частичные данные приложения
- **Ответы:**
  - **200 OK:** Возвращает частично обновленные данные приложения.

#### g. **Удалить приложение по ID**

- **Конечная точка:** `DELETE /app/{id}`
- **Описание:** Удаляет конкретное приложение по ID.
- **Параметры:**
  - **Параметр пути:** `id` (integer)
- **Ответы:**
  - **204 No Content:** Приложение успешно удалено.

### 2. **Транзакции**

#### a. **Получить все транзакции**

- **Конечная точка:** `GET /transaction/all`
- **Описание:** Получает список всех транзакций.
- **Параметры:**
  - **Параметры запроса (необязательно):**
    - `created_at` (string)
    - `status` (string)
    - `full_sum` (string)
- **Ответы:**
  - **200 OK:** Возвращает список транзакций.

#### b. **Создать транзакцию**

- **Конечная точка:** `POST /transaction/create`
- **Описание:** Создает новую транзакцию.
- **Параметры:**
  - **Тело запроса:**
    ```json
    {
      "title": "string",
      "full_sum": "number",
      "status": "string",
      "app": "integer"
    }
    ```
- **Ответы:**
  - **201 Created:** Возвращает данные созданной транзакции.

#### c. **Получить транзакцию по ID**

- **Конечная точка:** `GET /transaction/{id}`
- **Описание:** Получает подробности конкретной транзакции по ID.
- **Параметры:**
  - **Параметр пути:** `id` (string, UUID)
- **Ответы:**
  - **200 OK:** Возвращает подробности транзакции.

#### d. **Обновить транзакцию по ID**

- **Конечная точка:** `PUT /transaction/{id}`
- **Описание:** Обновляет подробности конкретной транзакции по ID.
- **Параметры:**
  - **Параметр пути:** `id` (string, UUID)
  - **Тело запроса:**
    ```json
    {
      "title": "string",
      "full_sum": "number",
      "status": "string",
      "app": "integer",
      "cvv": "string",
      "expired": "string",
      "account": "string",
      "client_id": "string",
      "client_secret": "string"
    }
    ```
- **Ответы:**
  - **200 OK:** Возвращает обновленные данные транзакции.

#### e. **Частично обновить транзакцию по ID**

- **Конечная точка:** `PATCH /transaction/{id}`
- **Описание:** Частично обновляет подробности конкретной транзакции по ID.
- **Параметры:**
  - **Параметр пути:** `id` (string, UUID)
  - **Тело запроса:** Частичные данные транзакции
- **Ответы:**
  - **200 OK:** Возвращает частично обновленные данные транзакции.

### 3. **Управление пользователями**

#### a. **Вход пользователя**

- **Конечная точка:** `POST /user/login`
- **Описание:** Вход пользователя.
- **Параметры:**
  - **Тело запроса:**
    ```json
    {
      "email": "string",
      "password": "string"
    }
    ```
- **Ответы:**
  - **201 Created:** Возвращает данные вошедшего пользователя.

#### b. **Выход пользователя**

- **Конечная точка:** `POST /user/logout`
- **Описание:** Выход пользователя.
- **Параметры:**
  - **Тело запроса:**
    ```json
    {
      "email": "string",
      "password": "string"
    }
    ```
- **Ответы:**
  - **201 Created:** Пользователь успешно вышел.

#### c. **Запрос на сброс пароля**

- **Конечная точка:** `POST /user/password/reset/`
- **Описание:** Запрос на сброс пароля.
- **Параметры:**
  - **Тело запроса:**
    ```json
    {
      "email": "string"
    }
    ```
- **Ответы:**
  - **201 Created:** Электронное письмо для сброса пароля отправлено.

#### d. **Подтверждение сброса пароля**

- **Конечная точка:** `POST /user/password/reset/confirm/`
- **Описание:** Подтверждение сброса пароля.
- **Параметры:**
  - **Тело запроса:**
    ```json
    {
      "uid": "string",
      "token": "string",
      "new_password": "string"
    }
    ```
- **Ответы:**
  - **201 Created:** Пароль успешно сброшен.

#### e. **Регистрация пользователя**

- **Конечная точка:** `POST /user/register`
- **Описание:** Регистрация нового пользователя.
- **Параметры:**
  - **Тело запроса:**
    ```json
    {
      "email": "string",
      "password": "string",
      "username": "string"
    }
    ```
- **Ответы:**
  - **201 Created:** Пользователь успешно зарегистрирован.

## Модели

### Модель приложения

- **AppCredentials:**
  - `id` (integer)
  - `client_id` (string)
  - `client_secret` (string)
  - `app` (integer)

- **AppWithCredentials:**
  - `id` (integer)
  - `credentials` (AppCredentials)
  - `title` (string)
  - `account` (string)
  - `is_active` (boolean)
  - `created_at` (string, date-time)
  - `updated_at` (string, date-time)
  - `owner` (integer)

- **AppAnalytics:**
  - `id` (integer)
  - `title` (string)
  - `income` (string)
  - `owner` (integer)
  - `account` (string)
  - `is_active` (boolean)
  - `

created_at` (string, date-time)
  - `updated_at` (string, date-time)
  - `transaction_count` (integer)

### Модель транзакции

- **Transaction:**
  - `id` (string, UUID)
  - `title` (string)
  - `full_sum` (number)
  - `status` (string)
  - `app` (integer)
  - `cvv` (string)
  - `expired` (string)
  - `account` (string)
  - `client_id` (string)
  - `client_secret` (string)
  - `created_at` (string, date-time)
  - `updated_at` (string, date-time)

### Модель пользователя

- **User:**
  - `id` (integer)
  - `password` (string)
  - `last_login` (string, date-time, nullable)
  - `is_superuser` (boolean)
  - `username` (string)
  - `first_name` (string)
  - `last_name` (string)
  - `email` (string)
  - `is_staff` (boolean)
  - `is_active` (boolean)
  - `date_joined` (string, date-time)
  - `groups` (array of integers)
  - `user_permissions` (array of integers)
